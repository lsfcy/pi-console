# Pi Console

简体中文 · [English](README.en.md)

一个管理多个 [Pi](https://pi.dev) 会话的 macOS 桌面应用。按项目查看会话，在标签页里直接使用 Pi，离开时也可以让任务继续运行。

![Pi Console 主界面](docs/images/main-dark.png)

## 为什么用它

同时处理几个项目时，终端窗口一多，很难记住哪个会话在哪、任务是否结束、上次聊到哪里。Pi Console 把项目、历史和运行中的会话放在一起，不用翻找终端窗口，也不用重新搭建 Pi 的使用环境。

它不是新的 AI 助手，也不替代 Pi：**对话、模型、工具和上下文仍由本机 Pi 负责。**

## 能做什么

- **管理项目和会话**：自动发现本地 Pi 历史，也可以手动添加项目；支持搜索、收藏、置顶、重命名和分叉会话。
- **同时处理多个任务**：一个项目可打开多个 Pi 标签；侧栏显示会话状态，`⌘J` 跳到需要处理的会话。
- **接着上次工作**：退出时可选择保留 Pi 进程，下次打开应用后重新连接；也可以选择结束进程。
- **查看用量**：按项目和时间查看会话数、Token、缓存和成本。统计来自本地 Pi 历史，不是账单数据。
- **沿用现有 Pi**：继续使用已有的模型、扩展、技能和配置。界面支持中文、英文及深浅色主题。

## 安装

目前只提供 **macOS Apple Silicon** 版本。

1. 安装并配置 [Pi](https://pi.dev)，确保在终端运行 `pi` 可以启动。
2. 从 [Releases](https://github.com/lsfcy/pi-console/releases) 下载最新的 macOS Apple Silicon ZIP。
3. 解压，将 `Pi Console.app` 拖入「应用程序」并打开。首次启动若被 macOS 拦截，可在「系统设置 → 隐私与安全性」中按提示允许。

如需核对文件完整性，可在同一目录下载 `SHA256SUMS.txt`，在终端执行 `shasum -a 256 -c SHA256SUMS.txt`。

安装包使用 ad-hoc 签名，**未通过 Apple Developer ID 签名和公证**。应用启动时及运行期间每小时检查 GitHub 是否有新版本，可在「设置 → 关于」关闭检查或手动检查；下载和安装仍需自行确认，不会自动替换应用。

## 用法

1. 打开应用，在侧栏选择已有项目，或点击「添加项目」。
2. 点击项目旁的 `+` 新建 Pi 会话；也可以从历史列表继续已有会话。
3. 在终端中照常使用 Pi。点击本地文件链接会在 Finder 中定位，不会自动执行文件。
4. `⌘W` 关闭当前标签并结束该 Pi 进程；任务仍在进行时会要求确认。
5. `⌘Q` 退出时，可以选择保留 Pi 继续运行，或结束所有受管 Pi 进程。关闭窗口只会隐藏应用。

| 常用操作 | 快捷键 |
|---|---|
| 命令面板 | `⌘K` |
| 新建会话 / 临时会话 | `⌘N` / `⌘⇧N` |
| 切换标签 | `⌘←` / `⌘→` |
| 切换侧栏会话 | `⌘↑` / `⌘↓` |
| 切换前十个可见项目 | `⌘1`–`⌘9`、`⌘0` |
| 下一个 / 上一个待处理会话 | `⌘J` / `⌘⇧J` |
| 打开当前项目的系统终端 | `⌘T` |
| 设置 / 快捷键列表 | `⌘,` / `⌘/` |

首次启动会显示可跳过的新手引导，可在「设置 → 新手引导」重新查看。引导展示当前配置的快捷键。

长按 `⌘` **0.5 秒**可查看导航提示；快捷键可在设置中修改。应用内的 `⌘ + 方向键` 用于导航，普通文本框保留系统编辑行为。

## 工作原理与数据

应用为每个 Pi 会话启动一个本地终端进程，在窗口里显示 Pi 自己的界面。选择保留进程退出时，本地 relay 继续持有终端；应用重新启动后通过受限的本地 Unix socket 连接并恢复画面。它不接管其他终端中运行的 Pi。

- Pi 历史通常位于 `~/.pi/agent/sessions`，也支持 Pi 配置的会话目录。查看和统计历史时不会改写会话文件；删除会话会移到系统废纸篓。
- 项目、设置及会话恢复信息保存在 `~/Library/Application Support/Pi Session Console/`。保留的后台进程仍会消耗系统资源，用完后可以结束。
- 应用不提供云同步，也不保存模型凭据或主动上传会话。启动时及运行期间每小时默认查询 GitHub 的公开版本信息，可在设置中关闭；Pi、模型服务及已安装的扩展可能自行联网。
- 本地文件链接只在 Finder 中定位；打开文件前请确认来源。

更多细节见 [架构说明](docs/architecture.md) 和 [安全说明](SECURITY.md)。

## 开发

需要 Node.js 22.12 或更新版本、Xcode Command Line Tools 和可运行的 Pi：

```sh
npm ci
npm start
```

`npm run sandbox` 使用独立配置目录。提交前可运行 `npm run check`；Electron 和真实终端回归需要可用的 macOS 图形环境，见 [贡献指南](CONTRIBUTING.md)。

## 限制

目前没有 Linux 或 Windows 安装包，不支持内置分屏或自动下载安装更新。Pi 在全屏终端模式运行，终端图片协议暂不启用。Pi 工具使用当前用户的权限，**本应用不是安全沙箱**。
